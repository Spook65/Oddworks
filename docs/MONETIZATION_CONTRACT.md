# ODDWORKS Monetization Contract

## Current MVP Position

Vertical Slice 0.1 contains no monetization.

Monetization should only be introduced after the core loop is sufficiently playable to evaluate independently. The game must be fun and understandable before purchases are layered onto it.

## Potential Future Monetization

Potentially acceptable future systems include:

- game passes
- deterministic developer products
- progression acceleration
- workshop cosmetics
- guaranteed cosmetic purchases
- additional display or customization options
- private servers
- subscriptions when justified

This document does not promise any particular monetization feature.

## Design Principles

Future monetization must follow these principles:

- purchases must clearly communicate what the player receives
- the free game must remain meaningfully playable
- monetization should complement the game rather than replace gameplay
- avoid deceptive urgency
- avoid fake discounts
- avoid intentionally confusing purchase UI
- avoid dark patterns

Purchases should support players who already enjoy ODDWORKS. They should not be used to hide a weak core loop.

## Paid Randomized Items

Paid randomized items are not categorically declared illegal by this project contract.

However, any future system where Robux or Robux-purchased currency can produce a randomized reward requires a separate monetization, policy/compliance, UX, and technical-security review before implementation.

No paid randomized items or gacha are permitted in the MVP.

## Copyright And IP

ODDWORKS production content should use original ODDWORKS characters and assets.

Do not assume an asset is legally usable because another Roblox game uses it. Licensed third-party IP requires documented authorization. The success of an infringing game does not prove permission.

## Implementation Rule

No purchase code, game pass checks, developer products, subscriptions, premium currency, or monetization UI should be added without a dedicated monetization implementation prompt that references this contract.
